# NumPy Aggregation Functions

### Aggregation

- Aggregation means reducing multiple 
  array values into a summary or result.

### Basic Aggregation Functions

- `np.sum()` → Calculates the total 
   of elements.
- `np.prod()` → Calculates the 
   product of elements.
- `np.min()` → Returns the minimum 
   value.
- `np.max()` → Returns the maximum 
   value.
- `np.mean()` → Calculates the 
   average.
- `np.median()` → Returns the median value.
- `np.std()` → Calculates standard 
   deviation.
- `np.var()` → Calculates variance.

### Axis

- `axis=0` → Performs the operation 
   column-wise.
- `axis=1` → Performs the operation 
   row-wise.

### argmin()

- `np.argmin()` returns the index of 
   the minimum value.

### argmax()

- `np.argmax()` returns the index of 
   the maximum value.

### Value vs Index

- `np.min()` → minimum value
- `np.argmin()` → index of minimum 
   value
- `np.max()` → maximum value
- `np.argmax()` → index of maximum 
   value
