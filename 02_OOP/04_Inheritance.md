# Inheritance in Python

## What is Inheritance?

- Inheritance is a mechanism that allows a child class to acquire the properties and methods of a parent class.

## Parent Class

- The class whose properties and methods are inherited is called the parent class.

## Child Class

- The class that inherits from another class is called the child class.

## Basic Syntax

```python
class Parent:
    pass

class Child(Parent):
    pass
```

## Benefits of Inheritance

- Code reusability
- Reduces duplicate code
- Allows child classes to extend parent classes

## Important Points

- A child class inherits from a parent class.
- The parent class is also called a base class.
- The child class is also called a derived class.
- A child class can use inherited methods.
- A child class can override inherited methods.
