# Encapsulation in Python

## What is Encapsulation?

- Wrapping data and functions into a single unit(object).

## Access Modifiers

Python uses naming conventions for controlling access:

- Public
- Protected
- Private

## Important Points

- Encapsulation bundles data and methods together.
- Public members can be accessed directly.
- `_` is used to indicate protected members.
- `__` is used to indicate private members.
- Getters are used to access private data.
- Setters are used to modify private data.
