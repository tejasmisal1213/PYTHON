# Polymorphism

- Polymorphism means one name can have different forms or behaviors.

## Operator Overloading
- When same operator is allowed to have different meaning according to context.

- Operator overloading means giving a special meaning to an operator for objects.


### Python uses special methods for operator overloading.

+  → __add__()
-  → __sub__()
*  → __mul__()
/  → __truediv__()
== → __eq__()


## Dunder Functions

- Dunder stands for **Double Underscore**.

- Dunder functions are special methods in Python that start and end with double underscores.

- They are also called **Magic Methods** or **Special Methods**.

### Examples

__init__() → Constructor
__add__()  → +
__sub__()  → -
__mul__()  → *
__eq__()   → ==
