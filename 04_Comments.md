# Comments in Python

## What are Comments?

Comments are used to explain code and make it easier to understand.

Python ignores comments during execution.

---

## Single-Line Comment

A single-line comment starts with `#`.
 
## Multi-Line Comment

Python does not have a dedicated multi-line comment syntax.

We commonly use triple quotes.

## Why Use Comments?

- Explain code
- Improve readability
- Help during debugging
- Make code easier to maintain
