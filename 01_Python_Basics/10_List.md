# List

## What is list
  A list is Built in data type that store set of values.
  A list is a collectionof multiple items stored in single variable.

  Lists are ordered , mutable and allow duplicate values.
  List can store diff data types(int , float, string etc.)

## Common List Methods

append()  --> Add item
insert()  --> Insert item
remove()  --> Remove item
pop()     --> Remove by index
sort()    --> Sort list
reverse() --> Reverse list
len()     --> Length of list
