# Loops in Python

  - are used to execute block of code repetedely.
  - are used to repeat instructions.

## Types of Loop
  * 1. for loop --> used to iterate over sequence or range

  * 2. While loop --> execute while the condtion is True.

## range()
- range(start,stop,step)

## Loop control statment
- break --> Stops the loop
- continue --> Skips current iteration
- pass --> Does nothing; used as a placeholder

## Important Points

- `for` is commonly used for iterating over sequences.
- `while` runs based on a condition.
- The `stop` value in `range()` is not included.
- A `while` loop must eventually make its condition False.
