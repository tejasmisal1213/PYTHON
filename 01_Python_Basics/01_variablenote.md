# Rules for Identifiers in Python

An identifier is the name used for variables, functions, classes, etc.

## Rules

1. Identifier can contain:
   - Letters (A-Z, a-z)
   - Digits (0-9)
   - Underscore (_)

2. Identifier cannot start with a digit.

   Valid:
     age = 21
     student1 = "Tejas"
   

   Invalid:
   1age = 21

3. Special characters are not allowed.

   Invalid:
    
   user-name = "Tejas"
   user@name = "Tejas"
    
4. Spaces are not allowed.

5. Python identifiers are case-sensitive.

   name = "Tejas"
   Name = "Rahul"
   Both are different variables.

6. Keywords cannot be used as identifiers.

   Invalid:
   
   if = 10
   class = "Python"
