# Strings in Python

## What is a String?

A String is a sequence of characters enclosed in quotes.

Strings can be written using:

- Single Quotes (' ')
- Double Quotes (" ")
- Triple Quotes (""" """)
 

## String Length

Use len() function.
 
## String Concatenation

Joining two strings.
 
first = "Tejas"
last = "Misal"

print(first + " " + last)

## String Repetition

 
print("Hi " * 3)


- Output

Hi Hi Hi

## Important String Methods

upper() → Converts to uppercase
lower() → Converts to lowercase
strip() → Removes spaces
replace() → Replaces text
split() → Splits string

 

## Strings are Immutable

Strings cannot be changed after creation.

name = "Python"
name[0] = "J"

## Difference between Function and Method?

A function is called independently, while a method is associated with an object and is called using dot notation.
